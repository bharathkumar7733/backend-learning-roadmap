# 🧪 Lab 06 - Automatic Book ID Generation

## Objective

Create a backend where the server automatically generates Book IDs instead of asking the user to provide them.

### Features

- Backend generates unique Book IDs
- Store books in an in-memory list
- Retrieve one book using Path Parameters
- Retrieve all books

### APIs

POST /book

GET /books/{book_id}

GET /books

### Concepts Learned

- Backend-generated IDs
- Dictionary Creation
- Python Lists as Temporary Database
- append()
- Path Parameters
- CRUD Foundations
